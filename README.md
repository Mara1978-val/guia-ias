# Guía de IAs — Todas las inteligencias artificiales y para qué sirven

Página estática (HTML + CSS + JS en un solo fichero, sin dependencias) con un **directorio de IAs en español**:
qué hace cada una, para qué sirve y **enlace directo de acceso** a la página oficial.

## Categorías

- 💬 Asistentes de conversación (ChatGPT, Claude, Gemini, Copilot, Grok, DeepSeek…)
- 🔍 Búsqueda con IA (Perplexity, Consensus, Elicit, NotebookLM…)
- 💻 Programación (Claude Code, GitHub Copilot, Cursor, OpenCode, Replit, v0, Bolt…)
- 🎨 Imagen y diseño (Midjourney, Stable Diffusion, FLUX, Firefly, Ideogram…)
- 🎬 Video (Sora, Veo, Runway, Kling, HeyGen…)
- 🎵 Audio y voz (ElevenLabs, Suno, Descript, Otter…)
- ✍️ Escritura y productividad (Grammarly, Notion AI, Gamma, DeepL…)
- 🧰 Plataformas para desarrolladores (Hugging Face, OpenRouter, Ollama, LM Studio…)

Incluye **buscador en vivo**, **filtros por categoría**, tabla "¿cómo elegir?" y guía gratis vs. de pago.

## Verla localmente

Doble clic en `index.html` o `npx serve .`

## Subirla a GitHub

```sh
git init
git add .
git commit -m "Guía de IAs"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPO.git
git push -u origin main
```

Luego: **Settings → Pages → Deploy from a branch → `main` / root**.

🧭 ¿Cómo elegir? Guía rápida

Si necesitas…Usa esta
Un asistente para todo (escribir, dudas, imágenes, voz)ChatGPT o Claude
Algo integrado con Google (Gmail, Docs, búsqueda)Gemini
ProgramarClaude Code, Cursor o GitHub Copilot
Programar gratis y libreOpenCode
Investigar con fuentes fiablesPerplexity (o Consensus si son estudios)
Una imagen bonitaMidjourney o ChatGPT/Gemini Images
Un vídeoSora o Kling
Una canciónSuno
Una voz o narraciónElevenLabs
Una presentaciónGamma
Traducir bienDeepL
Que tus datos no salgan de tu PCOllama o LM Studio
Usar muchos modelos desde un sitioPoe (chatear) u OpenRouter (desarrollo)
💡 Consejo para no perderse No necesitas todas: elige una generalista (ChatGPT/Claude/Gemini) + una para tu oficio (código, imagen, música…) y domina esas dos. El resto de esta página es para cuando aparezca una necesidad concreta.

💰 Gratis vs. de pago

  • Con plan gratuito puedes: chatear con límites diarios (ChatGPT, Claude, Gemini, DeepSeek, Le Chat, Kimi, Meta AI), buscar (Perplexity), generar imágenes (Canva, Leonardo, Kling) y crear música (Suno tiene nivel free con créditos).
  • De pago suele implicar: modelos más potentes, más límites, uso comercial de imágenes y colas prioritarias. Suele rondar los 10–20 €/mes (ChatGPT Plus, Claude Pro, Gemini Advanced, Cursor Pro…).
  • 100% gratis para siempre: las IAs open source (OpenCode, Stable Diffusion, Ollama + modelos como Llama, Qwen o DeepSeek).
  • Alternativa económica: paga por uso con OpenRouter en vez de suscripción: solo gastas lo que uses.
  • Estudiantes: muchas universidades dan acceso gratuito a ChatGPT Edu, Gemini o Copilot; pregúntalo en tu centro antes de pagar.
